Como usar o Sacred Atlas

🗺️
Navegar no mapa

Clique e arraste para mover. Use a roda do mouse ou os botões + / − para zoom.

📍
Marcadores

Clique em qualquer marcador para ver detalhes: evento, data, fonte e nível de certeza histórica.

🎨
Camadas por Tradição

Use o painel esquerdo para ativar/desativar tradições religiosas individualmente.

📅
Filtro de Período

Arraste os controles de período para filtrar eventos por época histórica. Use os atalhos rápidos.

🔎
Busca

Digite um local, evento ou tradição no campo de busca para encontrar marcadores específicos.

⚠️
Base da informação

Cada ponto indica se é história documentada, tradição religiosa, hipótese acadêmica ou local simbólico. Isso nunca é apagado.

Nota metodológica: Este atlas diferencia cuidadosamente entre narrativas históricas documentadas, tradições religiosas, hipóteses acadêmicas e locais simbólicos. Nenhuma tradição é tratada como hierarquicamente superior. Fontes são citadas em cada ponto.
